# ScreenLens Roadmap

План развития проекта ScreenLens — открытого аналога Google Lens и PowerToys Text Extractor для Windows.

---

## 🎯 Выполнено

- [x] **v0.1.0 (MVP)**:
  - Интерактивный полупрозрачный оверлей с перекрестием курсора (Tkinter DPI-Aware).
  - Высокоточный захват снимка в формате PNG.
  - Распознавание через локальный движок (Windows Media OCR + Tesseract OCR).
  - Консольный пайплайн с обработкой ошибок.

- [x] **v2.0.0 (Desktop Integration)**:
  - Фоновый режим (Daemon) с системным перехватом `Ctrl + Alt + Space`.
  - Независимость от раскладки клавиатуры (Win32 `RegisterHotKey` с физическими скан-кодами).
  - Автоматическое копирование результата в буфер обмена (`pyperclip`).
  - Системный звуковой сигнал Windows при успешном распознавании.

- [x] **v3.0.0 (Smart Actions & Standalone App)**:
  - **Системный трей**: фоновая иконка в трее Windows (`pystray`) с меню действий.
  - **Плавающая панель действий (Floating HUD)**: удобное окно сразу после выделения (Текст, Перевод, Gemini, Google Lens).
  - **Мгновенный перевод**: встроенный перевод на лету за 50 мс.
  - **QR & Штрихкоды**: автоматическая детекция и декодирование QR-кодов со снимка (`OpenCV`).
  - **ИИ-анализ**: мультимодальная интеграция с Google Gemini 3.5 Flash Lite (`gemini-3.5-flash-lite`).
  - **База данных SQLite**: сохранение истории снимков, текста, переводов и настроек пользователя.
  - **Настройки через GUI**: смена хоткея, языков, API-ключа Gemini, звука и автозагрузки с Windows.
  - **Автозапуск**: интеграция с реестром Windows `HKCU\...\Run`.
  - **Сборка в EXE**: автоматическая компиляция в единый портативный исполняемый файл через PyInstaller.

## 🚀 Будущие релизы (v3.5 - v4.0)

- [ ] **Экспорт таблиц**: извлечение табличных данных из скриншота и экспорт в Excel/CSV.
- [ ] **LaTeX формулы**: оптическое распознавание математических уравнений в формат LaTeX / Markdown.
- [ ] **Оффлайн перевод (Argos-Translate)**: перевод без подключения к интернету.
- [ ] **Пиксельная лупа (Magnifier)**: увеличение области вокруг курсора для выделения с точностью до 1 пикселя.
- [ ] **OCR видео и стримов**: периодический автоматический захват субтитров из воспроизводимого видео.
- [ ] **Плагины действий**: открытый API для добавления пользовательских действий по клику на выделенный текст.
