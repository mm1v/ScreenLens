# ScreenLens Roadmap

План развития проекта ScreenLens — открытого аналога Google Lens и PowerToys Text Extractor для Windows.

---

## 🎯 Текущий релиз

- [x] **v0.0.2 (Comss.one DoT, отказоустойчивый ИИ-прокси и стабилизация UI)**:
  - **Расширенный пул DoT (порт 853)**: интеграция резолверов `dns.comss.one` и `dns.dns-ai.ru` для гарантированного обхода геоблокировок Google Gemini без сторонних VPN.
  - **Автоматический failover SNI-прокси**: пул зарубежных SNI-прокси (Амстердам, Нидерланды) с механизмом кулдауна и автоповтором запроса при сбое узла.
  - **Стабилизация UI**: устранение дедлоков основного потока при открытии окон настроек и истории.
  - **Улучшения ИИ-режима**: фикс отправки запроса по клавише Enter, безопасная обработка ошибок без затирания текста и защита от кодировочных сбоев Windows CP1251.

- [x] **v0.0.1 (Первая тестовая версия / Standalone Desktop)**:
  - **Интерактивный оверлей**: полупрозрачный селектор с затемнением и поддержкой мультимониторных конфигураций.
  - **Фоновый режим и трей**: иконка в системном трее Windows (`pystray`) и глобальный хоткей `Ctrl + Alt + Space` (`RegisterHotKey`).
  - **Dual OCR Engine**: Windows Media OCR (без зависимостей) и Tesseract OCR.
  - **Плавающая панель действий (Floating HUD)**: копирование, перевод за 50 мс, кнопка Google Lens.
  - **ИИ-анализ**: мультимодальная интеграция с Google Gemini 3.5 Flash Lite (`gemini-3.5-flash-lite`).
  - **Обход геоблокировок (DNS-AI)**: встроенный DoT-резолвер (порт 853) и SNI-проксирование без VPN.
  - **QR & Штрихкоды**: автоматическая детекция и декодирование QR-кодов (`OpenCV`).
  - **База данных SQLite**: сохранение истории снимков, текста, переводов и настроек.
  - **GUI-настройки**: смена хоткея, языков, API-ключа Gemini, звука и автозагрузки с Windows.
  - **Сборка в Standalone EXE**: компиляция в единый исполняемый файл через PyInstaller.

## 🚀 Будущие релизы (v0.1.0 - v1.0.0)

- [ ] **Экспорт таблиц**: извлечение табличных данных из скриншота и экспорт в Excel/CSV.
- [ ] **LaTeX формулы**: оптическое распознавание математических уравнений в формат LaTeX / Markdown.
- [ ] **Оффлайн перевод (Argos-Translate)**: перевод без подключения к интернету.
- [ ] **Пиксельная лупа (Magnifier)**: увеличение области вокруг курсора для выделения с точностью до 1 пикселя.
- [ ] **OCR видео и стримов**: периодический автоматический захват субтитров из воспроизводимого видео.
- [ ] **Плагины действий**: открытый API для добавления пользовательских действий по клику на выделенный текст.
