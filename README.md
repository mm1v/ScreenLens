> **ScreenLens** — современное открытое Windows-приложение для мгновенного захвата экрана, интеллектуального интерактивного выделения текста в стиле Google Lens и Android «Circle to Search», высокоточного OCR, контекстного перевода и мультимодального анализа с помощью Google Gemini Vision.

---

## ✨ Ключевые возможности

- 🔲 **Интерактивное выделение текста (Google Lens UX)**:
  - Выделение распознанного текста непосредственно на оригинальном изображении без искажения подложки и дублирования букв.
  - Пословные хитбоксы, плавное многострочное выделение перетаскиванием мыши, контекстная плавающая кнопка быстрого копирования.
  - Поддержка горячих клавиш `Ctrl + C`, `Enter`, `Ctrl + A` и `Esc` в любой языковой раскладке.
- 🌐 **Встроенный перевод (In-Place Translation)**:
  - Наложение переведённого текста поверх исходного снимка с автоматическим маскированием и адаптивной типографикой.
  - Возможность частичного и полного копирования перевода прямо со скриншота.
- 🔤 **Высокоточный двойной OCR-движок**:
  - Нативный Windows Media OCR и Tesseract OCR с автоматическим выбором оптимального движка.
  - Двухмерное пространственное объединение результатов (Spatial IoU) для одновременного распознавания смешанного русско-английского текста (`rus+eng`).
  - Кластеризация строк и разделение столбцов таблиц для исключения межколоночного смешивания.
  - Сохранение технических идентификаторов (`snake_case`, `camelCase`, спецсимволы `_`, `%`, `+`, `\n`) и защита от омоглифов (`0` vs `З`, `96` vs `%`, `Ьееп` vs `been`).
- 📋 **Умный буфер обмена**:
  - Полное отсутствие автоматического засорения буфера при кадрировании или смене режимов.
  - Контекстное копирование: снимок копируется только при явном нажатии кнопки «Копировать», а выделенный текст — по клику или `Ctrl + C`.
- 🤖 **Мультимодальный анализ Google Gemini Vision**:
  - Интеллектуальный анализ выделенной области: разбор кода, решение математических задач, описание графиков и диаграмм.
  - Встроенный обход региональных ограничений через DNS-over-HTTPS (DoT) и автоматический SNI-прокси.
- ⌨️ **Глобальный доступ и интеграция**:
  - Win32 перехват сочетания клавиш (`Ctrl + Alt + Space`) поверх любых окон и полноэкранных приложений.
  - Тихий фоновый режим в системном трее, автозапуск с Windows.
  - Локальная база истории захватов на SQLite с поиском и превью.
- 📦 **Автономность**:
  - Сборка в единый переносимый файл (Standalone Portable EXE), не требующий установки внешних библиотек или Python.

```text

│   ├── test_screenlens.py      # Набор из 87 автоматизированных unit-тестов
│   ├── test_storage.py         # Тесты базы данных и настроек
│   └── benchmark/              # Эталонные изображения и замер точности (CER/WER)
│       └── evaluate.py
│
```

## 🚀 Быстрый старт

### Вариант 1. Запуск готового приложения
Запустите `ScreenLens.exe` (портативная версия). Иконка приложения появится в системном трее рядом с часами.

### Вариант 2. Запуск из исходного кода

```powershell
# 1. Клонирование репозитория
git clone https://github.com/mm1v/ScreenLens.git
cd ScreenLens

# 2. Создание и активация виртуального окружения
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# 3. Установка зависимостей
pip install -r requirements.txt

# 4. Запуск десктопного приложения
python app.py
```

### Вариант 3. Использование в режиме командной строки (CLI)

```powershell
# Разовый интерактивный захват с выводом текста в консоль
python main.py

# Фоновый консольный демон с автопереводом на русский язык
python main.py --daemon --translate ru
```

## ⌨️ Горячие клавиши и управление

| Действие | Комбинация / Жест | Описание |
| :--- | :--- | :--- |
| **Активация оверлея** | `Ctrl + Alt + Space` | Открывает область захвата поверх любого приложения |
| **Выделение области** | Зажатие ЛКМ + движение | Выделяет область на экране для последующих действий |
| **Подстройка границ** | Перетаскивание маркеров | 8 круглых маркеров позволяют изменить размер рамки |
| **Режим «Текст»** | Кнопка **Текст** в HUD | Активирует интерактивное выделение текста Google Lens |
| **Выделение слов** | ЛКМ drag по тексту | Выделяет слова или строки прямо на изображении |
| **Копирование текста** | `Ctrl + C` или `Enter` | Копирует выделенный текст в системный буфер обмена |
| **Режим «Перевод»** | Кнопка **Перевод** в HUD | Накладывает переведённый текст поверх исходного снимка |
| **Режим «ИИ»** | Кнопка **ИИ** в HUD | Открывает окно диалога с Google Gemini Vision |
| **Закрытие / Отмена** | `Esc` | Закрывает оверлей без применения изменений |
