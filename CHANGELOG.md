# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.0.5] - 2026-10-14

### Added
- **Фоновая упреждающая обработка (Preemptive Background Pipeline)**:
  - OCR-распознавание и перевод запускаются в фоне сразу в момент завершения выделения области на экране.
  - Мгновенное открытие и отображение слоёв «Текст» и «Перевод» при клике на соответствующие кнопки панели без ожидания и блокировок интерфейса.
  - Интеллектуальное кэширование результатов распознавания и перевода по координатам выделенной рамки.
- **Поддержка произвольных AI URL и моделей (Flexible AI Configuration)**:
  - Поля настройки в интерфейсе: `URL` (базовый URL `https://generativelanguage.googleapis.com/v1beta`), `Model` (`gemini-3.5-flash-lite` или произвольная модель) и `API KEY`.
  - Автоматическая генерация полного эндпоинта формата `/models/{model}:generateContent` с аутентификацией через заголовок `x-goog-api-key`.
  - Безопасное хранение настроек (по умолчанию поле API-ключа пустое в чистой установке).
- **Многомониторная поддержка и адаптивное позиционирование (Multi-Monitor Awareness)**:
  - Интеграция с Win32 API (`MonitorFromPoint` и `GetMonitorInfoW`), определяющая рабочую область `rcWork` активного монитора с вычетом панели задач Windows.
  - Автоматическое размещение плавающей панели внутри выбранной области с безопасным отступом при полноэкранном выделении или нехватке места.
  - Исключение выхода HUD и карточек результатов за пределы экрана или под панель задач на дополнительных мониторах с любым разрешением.
- **Интерактивные эффекты**:
  - Подсветка контура (hover outline) при наведении курсора на кнопки «Копировать» и «Закрыть».

### Changed
- **Эргономика диалога ИИ**:
  - Ограничение максимальной высоты окна карточки ИИ на 5% меньше экрана для гарантированной видимости на любых дисплеях.
  - Реальный плейсхолдер в поле ввода вопроса: текст подсказки отделён от пользовательского ввода, кнопка «Спросить» неактивна до ввода реального текста, клавиша Enter отправляет запрос только при наличии пользовательского вопроса.

### Fixed
- **Производительность попапа ИИ**:
  - Устранена ~5-секундная задержка при повторном открытии попапа ИИ за счёт мгновенного расчёта переноса строк в Python вместо синхронных запросов геометрии к неразмеченным окнам Tkinter.
  - Корректное уничтожение фрейма содержимого `content_frame` и гарантированная отмена таймеров `after` (`after_cancel`) при закрытии карточки, предотвращающие утечки памяти и зависшие фоновые циклы.
  - Реализован toggle-off при повторном клике на кнопку «ИИ» на панели действий.

## [0.0.4] - 2026-10-14

### Added
- **Продвинутый AI-режим на базе Google Gemini Vision**:
  - Компактная боковая панель с предпросмотром миниатюры, быстрым вводом и ответом модели рядом с выделенной областью.
  - Прямая передача оригинального полноцветного изображения мультимодальной нейросети (`GeminiChatSession`) с OCR-контекстом.
  - Поддержка многоэтапного контекстного диалога (follow-up вопросы по снимку без повторной отправки изображения).
  - Standalone полнофункциональное окно расширенного чата (`AIExtendedChatWindow`) с сохранением сессии, чипами быстрых подсказок и экспортом полного транскрипта беседы.
  - Асинхронное выполнение запросов к Gemini в отдельном потоке без блокировки интерфейса Tkinter с динамическим отображением статуса.
- **Новый дизайн и эргономика попапа ИИ**:
  - Скругления окон ввода и вывода (`RoundedInputBox`, `RoundedResponseBox`) с радиусом 12px, антиалиасингом и стилизованным тёмным контуром.
  - Быстрые действия в одну строку: «Объяснить», «Текст», «Перевод», «Код» с адаптивными капсульными кнопками.
  - Минималистичная векторная иконка копирования (двойной лист) с анимацией подтверждения (зелёная галочка `✓`).
  - Кастомный адаптивный тёмный скроллбар (`DarkScrollbar`), гармонично встроенный в дизайн и автоматически скрывающийся при полном помещении контента.
  - Динамическое увеличение высоты карточки вниз при получении ответа от нейросети.

### Changed
- **Улучшения интерактивного захвата**:
  - Высокопроизводительный 60 FPS рендеринг рамки захвата с прозрачной незатенённой областью внутри выделения.
  - Аккуратные угловые маркеры с уменьшенным радиусом скругления и контрастной мягкой тенью.
  - Автоматическое боковое позиционирование попапа ИИ справа от рамки (или внутри области при нехватке экранного пространства).

### Fixed
- **Стабильность перевода**:
  - Трёхуровневая отказоустойчивая архитектура перевода (Google Chrome Extension Endpoint → Google Translate single API → MyMemory API), предотвращающая ошибки 429 Too Many Requests.
- **Стабильность интерфейса**:
  - Устранена ошибка `UnboundLocalError: cutout_img_id` и исключение `TclError` при быстром перетаскивании рамки.
  - Гарантированное сохранение введённого пользователем текста запроса при сетевых ошибках или таймаутах.

## [0.0.3] - 2026-10-14

### Added
- **Интерактивное выделение текста (Google Lens UX)**:
  - Выделение распознанного текста непосредственно на оригинальном изображении без искажений и наложения дублирующих букв.
  - Пословные хитбоксы, плавное многострочное выделение перетаскиванием мыши, всплывающая капсула быстрого копирования.
  - Горячие клавиши `Ctrl + C`, `Enter`, `Ctrl + A` и `Esc` для обеих раскладок (RU/EN).
- **Встроенный перевод (In-Place Translation)**:
  - Наложение переведённого текста поверх оригинала со сглаженными масками подложки и адаптивным шрифтом.
- **Бенчмарк и расширенное тестирование**:
  - Набор эталонных изображений и фреймворк оценки (`tests/benchmark/evaluate.py`), покрывающий 6 категорий (терминал, таблицы, тёмные/светлые темы, иконки, код).
  - Расширение тестовой базы до 87 автоматических unit-тестов. Точность распознавания технических идентификаторов 95.7%, CER 2.50%.

### Changed
- **Политика буфера обмена**:
  - Отключено автоматическое копирование скриншота при выделении области. Изображение копируется строго по нажатию кнопки «Копировать».
  - В режимах текста и перевода `Ctrl + C` или кнопка копируют текст вместо изображения.
- **Floating Action HUD**:
  - Обновлена плавающая панель с капсульной геометрией Google Lens, индикацией активного режима и плавным переключением.
- **Документация**:
  - Обновлён `README.md` в едином профессиональном стиле с удалением жестко прописанной версии в заголовке.

### Fixed
- **OCR и двухязычное объединение**:
  - Устранено дублирование слов при совместном распознавании `rus+eng` с помощью пространственного 2D IoU-сопоставления.
  - Исправлено слияние колонок в табличных сетках благодаря кластеризации строк по горизонтали и вертикали.
  - Устранена путаница кириллических омоглифов в английском тексте (`f1ash` → `flash`, `Ьееп` → `been`, `по 1опде` → `no longer`, `Google AI Studio`, `client UI`, даты, маркеры).
  - Восстановлено точное распознавание спецсимволов (`_`, `%`, `+`, `\n`) и цифр (`0` vs `З`, `96` vs `%`).

## [0.0.2] - 2026-10-10

### Added
- **Отказоустойчивый обход геоблокировок Gemini**:
  - Интеграция DoT-резолверов `dns.comss.one` и `dns.dns-ai.ru` (порт 853).
  - Автоматический failover пул зарубежных SNI-прокси без необходимости сторонних VPN.
- **Улучшения UI**:
  - Отправка запроса в Gemini AI по нажатию клавиши `Enter`.

### Fixed
- Устранены взаимные блокировки (deadlocks) в основном потоке при открытии диалогов настроек и истории.
- Безопасная обработка исключений при генерации всплывающих уведомлений (toasts).
- Защита от сбоев кодировок Windows CP1251 в консоли.

## [0.0.1] - 2026-10-06

### Added
- Первый публичный релиз десктопного приложения ScreenLens для Windows.
- Интерактивный оверлей захвата экрана с затемнением и 8 маркерами настройки границ.
- Фоновый режим с иконкой в системном трее Windows (`pystray`).
- Глобальный хоткей `Ctrl + Alt + Space` через Win32 API.
- Двойной OCR-движок: нативный Windows Media OCR и Tesseract OCR.
- Плавающий HUD с быстрыми действиями: Текст, Перевод, ИИ, Google Lens, Копировать.
- Мультимодальный анализ на базе Google Gemini Vision (`gemini-3.5-flash-lite`).
- QR & Barcode сканер с автоматическим определением ссылок.
- Локальная база данных SQLite для хранения истории снимков и настроек.
- Скрипт сборки в автономный переносимый файл `ScreenLens.exe` через PyInstaller.
